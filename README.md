## 先说清楚：上海CN2不是“出国专线”

这是搜这个关键词的人最容易踩的第一个坑。

MKCloud官方知识库对上海CN2的定义写得很明白：**上海动态联通入口 + 上海电信CN2出口**，两个端都在上海。它是一个“国内优化”产品，不是香港、日本或美国出口的跨境专线。

具体拆开是这样：

- **入口**：你从本地连接服务器的地址，走上海动态联通线路
- **出口**：服务器向外访问业务时发出的地址，走上海电信CN2线路

也就是说，它的定位是“需要上海本地线路质量的国内业务”，而不是“从上海连到全世界”。官方甚至专门提醒：不能仅凭"CN2"这个名称就认定它全程是CN2 GIA——目前公开资料只写到“上海电信CN2出口”，没有足以确认全程GIA的材料。如果你的采购清单里GIA是硬性要求，下单前要先和客服确认清楚。

还有一点官方写得相当直白：动态IP不保证规避风控，也不等于提高账号安全。频繁变化的登录环境反而可能触发平台额外验证。所以如果你看到某些宣传说“动态IP防封必备”，那个说法本身就不靠谱。

这款产品的购买限制比普通VPS多不少，下单前逐条核对，能省掉后面很多麻烦。

**第一，必须实名。** 该产品需遵守中国法律，下单需要提交中国身份信息做实名认证，个人用户用手机号、姓名、身份证号，企业用户需要营业执照编号和法人信息。这是合规产品绕不开的一步，没有“匿名购买”的选项。

## 什么业务适合，什么业务不该买这个

根据官方知识库的适用说明和产品定位，适合评估上海CN2的场景大致是：业务服务器需要放在上海本地、对出站线路质量有要求、目标访问对象在国内或对出口方向不敏感、且能接受动态IP的业务。典型比如国内侧的业务部署、需要上海电信出口质量的对外服务。

以下几种情况，这产品并不对口：

- **需要海外出口的业务。** 做面向香港、日本、美国方向的业务，应该看MKCloud的跨境产品线，而不是上海CN2。同样是上海入口，沪港专线端内延迟约21ms，沪日约25~28ms，沪美约124~134ms，这些才是“出国”的选择。
- **需要固定IP做白名单的业务。** 动态IP的变化规则没有公开，对接入方IP有白名单要求的系统，不能自行假设IP多久变一次，这个风险没人替你兜底。
- **想拿来当海外IP、解锁流媒体或账号防封的。** 官方明确写了原生IP、住宅IP、流媒体解锁不是已承诺能力，出口也不接受外部连入。
- **预算在几百块量级的个人用户。** 这产品的价格结构决定了它是给有真实业务需求、算得清账的买家准备的。

## 常见问题

**这个产品是CN2 GIA吗？**
官方口径是“上海电信CN2出口”，未承诺全程GIA。如果GIA是你的硬指标，下单前取得对应书面说明。

**动态IP多久变一次？**
暂不公开。需要固定白名单的业务不应以猜测为采购依据。

**可以用它连海外平台吗？**
出口在上海，不是海外落地IP。海外方向请看沪港、沪日、沪美等跨境产品。

**买完多久能用？**
7天内交付，下单后提交工单，官方会对接注意事项。

**能退吗？**
仅质量问题退款，且需要提供具体的延迟、速度数据作为证据，开通后不支持换地域。
